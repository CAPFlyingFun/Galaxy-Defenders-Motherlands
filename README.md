# Galaxy Defenders: Motherlands

A 3D dome-defense game. One heroine, built on the Custom Character Builder body, defends a domed city from
enemies coming from every side of the sky. The 3D successor to the HTML prototype "Galaxy Defenders: Mother
Overlord" (kept in `docs/reference/`).

- Play: https://capflyingfun.github.io/Galaxy-Defenders-Motherlands/
- `Game/` is everything built for this game (TypeScript, Vite, Three.js).
- `Char_B/` is a copy of the Custom Character Builder System, never edited by hand (`Char_B/COPIED_FROM.md`).

```
cd Game
npm install
npm run dev
```
